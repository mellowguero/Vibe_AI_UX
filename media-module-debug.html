MediaModule Debug Page

Test YouTube playback, audio playback, and artwork fetching with external URL input

Supported formats:
  • YouTube URLs: https://www.youtube.com/watch?v=VIDEO_ID or https://youtu.be/VIDEO_ID
  • Audio URLs: Any direct audio file URL (e.g., https://example.com/audio.mp3)
  • Song titles: Plain text like Artist - Song (will search YouTube)
